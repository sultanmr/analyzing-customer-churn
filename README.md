# Customer Churn Rate Analysis in Tableau

## Overview
This project analyzes customer churn by examining key factors such as age groups, data usage plans, international calling plans, payment methods, and contract types. By segmenting data based on these attributes, the analysis identifies patterns contributing to customer attrition. The insights inform strategies to enhance customer retention, improve service offerings, and reduce churn rates, fostering greater customer loyalty and satisfaction.

## Live Link
https://public.tableau.com/app/profile/sultan.riaz/viz/CustomerChurnRateAnalysis_17213047426100/ChurnAnalysis

## Key Features
- **Data Segmentation**: Categorizes customers based on age, data usage, payment methods, and contract types.
- **Churn Pattern Analysis**: Identifies factors associated with higher churn rates.
- **Visual Insights**: Utilizes Tableau to create dashboards and visualizations for easy interpretation.
- **Actionable Recommendations**: Provides strategies to improve retention and reduce churn.

## Tools and Technologies
- **Tableau**: For data visualization and dashboard creation.
- **Data Analysis Tools**: Python and SQL for data preprocessing and analysis.

## Project Goals
1. Identify key drivers of customer churn.
2. Provide actionable insights to improve customer retention.
3. Enhance service offerings based on customer needs.
4. Develop a data-driven approach for reducing churn rates.

## How to Use
